## Installation

You can install the development version of OmopOnPostgres from
[GitHub](https://github.com/) with:

``` r

# install.packages("devtools")
devtools::install_github("ohdsi/OmopOnPostgres")
```

## Example

``` r

library(OmopOnPostgres)
```
